# CS300-DSA-Analysis-and-Design

What was the problem you were solving in the projects for this course?
  - In the first project I solved various approaches to loading in a file, creating data objects, and searching for courses using pseudocode with various data types. The data types were vectors, hash tables, and binary search tree's. I then developed pseudocode for printing each type of list in alphanumeric order and completed a runtime analysis of this. I chose vector's do to there great strengths with the functionality of this application, however binary search trees were also a good canidate due to its natural order. The one that had no benefits here was hash table is it was naturally unondered and didn't have much benefit in other categories compared to the other two data types. In project two, I chose one data type out of the three which was vector and developed an application that would take in a csv file of computer sciene courses and then print or search through them.

How did you approach the problem? Consider why data structures are important to understand.
  - Every somewhere application solves a problem or problems. The first thing I did was look at what requirements had to be met by the application, then I looked at each data structure to see what strengths and weaknesses helped meet or hinder certain application requiremnets. The vector hit all the main requirements with the exception of one issue. It's not naturally ordered, and a sorting function can be costly. However, using the quicksort algorithm I was able to find an efficient algorithm for sorting. The other great point is that vector sorting becomes more costly with big data which a college courses file would never become that large. This made it so the binary search tree's natural order was less important because that data structure naturally more costly regardless of size.
